# Relex 首版功能设计

工作中感到焦虑或反复挂心时，打开 Relex 就能开始一分钟呼吸，或把心事记下来。两种方式独立使用，练习结束也能直接进入记录。

## 方案比较

- 只做呼吸最容易打开使用，但无法把反复挂心的事留下来。
- 呼吸与心事备忘两个独立入口各自完成一件事。用户确认首版采用这个方案。
- 加入感官练习会让不想跟着呼吸的人多一个选项。留待后续考虑。

## 行为

- 呼吸约一分钟，默认静音。用文字和圆形动画引导，不憋气，允许自然呼吸。支持暂停、继续、提前结束和再来一次，后台暂停。
- 记录包含必填的心事和可选的下一步，允许独立新增、查看、修改和删除。按创建时间倒序，编辑不改变顺序。删除前确认。
- Expo 应用可以离线工作，记录保存在本地。首版范围为呼吸和心事备忘。
