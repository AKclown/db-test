# Relex Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 用户一键开始静音呼吸，或离线保存并管理心事。
**Architecture:** 小型 Expo 应用，首页连接呼吸和备忘录，使用 AsyncStorage 持久化备忘录。
**Tech Stack:** Expo、React Native、TypeScript、pnpm。
**Spec:** docs/superpowers/specs/2026-11-25-relex-design.md

## Global Constraints

- 首版功能限定为呼吸和心事备忘。
- 简体中文界面，练习约一分钟，静音运行。记录使用本地存储。

## Review Focus

- 暂停与后台中断不消耗练习时间。
- 取消删除或放弃编辑时保留已存记录。
- 记录读取或保存失败时保留已有数据或当前输入。
- 空白心事不能保存，下一步可以留空。
- 应用重开后仍能看到记录和编辑结果。

### Task 1: Expo 与呼吸

- [ ] 配置 Expo 入口、平台依赖和项目脚本，验证依赖兼容性。
- [ ] 在 App.tsx 接入首页和呼吸页。在 src/Breathe.tsx 实现计时与动画。用单测验证阶段和结束边界，通过浏览器检查开始、暂停、继续、结束、再来一次。

### Task 2: 心事备忘

- [ ] 在 src/Notes.tsx 接入本地加载、新建、编辑与确认删除。写入成功才更新已保存列表。
- [ ] 验证空白提交、取消删除、保存后刷新、编辑和删除后的持久化。运行类型检查、单测和打包。
